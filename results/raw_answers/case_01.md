# Кейс №1. Синтаксическая ошибка (пропущена точка с запятой)

## Ответ модели Yandex GPT

**Шаг 1 (Синтаксис):** Есть ошибка — в строке `int x = 5` пропущена точка с запятой.

**Шаг 2 (Типы):** Ошибок нет.

`x` объявлена как `int` и инициализируется целым литералом `5` — типы совместимы. Метод `cout <<` используется корректно.

**Шаг 3 (Логика):** Ошибок нет.

Код выводит значение `x`, что соответствует задаче программы.

**Шаг 4 (Память):** Ошибок нет.

Динамическое выделение памяти не используется, массивов нет — выход за границы, утечки и двойное удаление исключены.

**Шаг 5 (Деление):** Ошибок нет.

Операция деления в коде отсутствует.

**Вывод:** Дефект один — синтаксический: отсутствие `;` после `int x = 5`. Без него компиляция не пройдёт (ошибка вида `expected ';' before 'cout'`). Логика, типы и работа с памятью корректны.

**Исправленный код:**

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 5;
    cout << x << endl;
    return 0;
}
```
