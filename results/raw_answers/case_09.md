# Кейс №9. Ошибка управления ресурсами (утечка памяти)

## Ответ модели Yandex GPT

**Шаг 1 (Синтаксис):** Ошибок нет — все точки с запятой на месте, скобки сбалансированы.

**Шаг 2 (Типы):** Ошибок нет — `data` имеет тип `int*`, элементы типа `int`, присваивание `data[i] = i` корректно.

**Шаг 3 (Логика):** Есть ошибки — формально код соответствует задаче, но ветка досрочного выхода устроена так, что нарушает намерение автора из п. 4: сообщение выводится, функция завершается, однако память при этом не освобождается.

**Шаг 4 (Память):** Есть ошибки — утечка памяти. Так как `data[0] = 0` гарантированно (массив заполняется значениями 0..99), условие `if (data[0] == 0)` всегда истинно, и выполнение всегда уходит в ветку с `return` до строки `delete[] data`. Выделенные 400 байт (`100 * sizeof(int)`) остаются занятыми до конца работы программы. Это классический «ранний return в обход освобождения ресурса».

**Шаг 5 (Деление):** Ошибок нет — операций деления в коде нет.

**Вывод:** единственный дефект — утечка динамически выделенного массива при досрочном выходе из `process()`. Строка `delete[] data;` недостижима, поскольку первый элемент всегда равен 0. Исправление — освобождать память перед каждым выходом или, что надёжнее, делегировать владение памяти RAII-обёртке (`std::vector` либо `std::unique_ptr<int[]>`): тогда память освободится автоматически при любом выходе, включая исключения.

**Исправленный код:**

```cpp
#include <iostream>
#include <memory>
using namespace std;

void process() {
    unique_ptr<int[]> data(new int[100]);
    for (int i = 0; i < 100; ++i) {
        data[i] = i;
    }
    if (data[0] == 0) {
        cout << "empty start\n";
        return;  // память освободится автоматически
    }
    // память также освободится автоматически здесь
}

int main() {
    process();
    return 0;
}
```

Минимальная альтернатива без смены стиля (ручное управление, как в оригинале):

```cpp
void process() {
    int* data = new int[100];
    for (int i = 0; i < 100; ++i) data[i] = i;

    if (data[0] == 0) {
        cout << "empty start\n";
        delete[] data;   // освобождаем перед выходом
        return;
    }

    delete[] data;
}
```
Первый вариант предпочтительнее: он устойчив к добавлению новых путей выхода и к исключениям в будущем коде.
