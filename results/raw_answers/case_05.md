# Кейс №5. Логическая ошибка (неверное условие)

## Ответ модели Yandex GPT

**Шаг 1 (Синтаксис):** Ошибок нет — точки с запятой и скобки в порядке.

**Шаг 2 (Типы):** Ошибок нет — `int sum`, `int i`, вывод через `cout` корректны.

**Шаг 3 (Логика):** Есть ошибка.

Условие `if (i % 2 == 0)` отбирает чётные числа, а по задаче нужны нечётные. Программа выведет `2 + 4 + 6 + 8 + 10 = 30` вместо ожидаемого `25`.

**Шаг 4 (Память):** Ошибок нет — динамической памяти нет, выхода за границы массивов нет (массивов нет вовсе).

**Шаг 5 (Деление):** Ошибок нет — делитель `2` — константа, деления на ноль не возникнет.

**Вывод:** Единственный дефект — логический: проверка на чётность вместо нечётности. Исправляется инверсией условия на `i % 2 != 0` (или эквивалентно `i % 2 == 1` для положительных `i`).

**Исправленный код:**

```cpp
#include <iostream>
using namespace std;

int main() {
    int sum = 0;
    for (int i = 1; i <= 10; ++i) {
        if (i % 2 != 0)
            sum += i;
    }
    cout << sum << endl;
    return 0;
}
```

Теперь программа выводит `25` — как и ожидалось.

**Шаг 4 (Память):** Ошибок нет.

Нет динамической памяти, массивов, указателей — утечек и выходов за границы невозможны.

**Шаг 5 (Деление):** Ошибок нет.

Деления нет; `%` на константу `2` — деления на ноль не возникает.

**Вывод:**

Логическая ошибка: перепутано условие чётности. Вместо нечётных чисел суммируются чётные, результат будет 30 вместо ожидаемых 25. Синтаксис, типы, память и деление — в порядке.

**Исправленный код:**

```cpp
#include <iostream>
using namespace std;

int main() {
    int sum = 0;
    for (int i = 1; i <= 10; ++i) {
        if (i % 2 != 0)      // нечётные числа
            sum += i;
    }
    cout << sum << endl;     // 25
    return 0;
}
```

Альтернатива без ветвления (шаг 2, начиная с 1):

```cpp

```

Логическая ошибка в условии `if (i % 2 == 0)`. По условию задачи нужно складывать нечётные числа, а проверка `i % 2 == 0` отбирает чётные. В результате программа выведет `30` (2+4+6+8+10) вместо ожидаемых `25` (1+3+5+7+9).

**Исправленный код:**

```cpp
#include <iostream>
using namespace std;

int main() {
    int sum = 0;
    for (int i = 1; i <= 10; ++i) {
        if (i % 2 != 0)      // проверяем на нечётность
            sum += i;
    }
    cout << sum << endl;     // выведет 25
    return 0;
}
```

Небольшой совет на будущее: для проверки на нечётность часто пишут `i % 2 == 1` — это тоже корректно для положительных чисел, но `i % 2 != 0` более универсально и безопаснее работает с отрицательными значениями (там остаток может быть `-1`).
