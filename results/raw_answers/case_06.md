# Кейс №6. Логическая ошибка (перепутано сравнение)

## Ответ модели Yandex GPT

**Шаг 1 (Синтаксис):** Ошибок нет.

**Шаг 2 (Типы):** Ошибок нет.

**Шаг 3 (Логика):** Есть ошибки.

- Код ищет максимум (`max = a[i]` при условии `a[i] > max`), а по задаче нужно найти минимум. Переменная инициализирована первым элементом корректно, но направление сравнения противоположно цели.
- Комментарий/задача противоречат выводу: программа напечатает `max = 5` вместо ожидаемого минимума `1`.
- Мелочь, но сама переменная называется `max`, что усугубляет путаницу.

**Шаг 4 (Память):** Ошибок нет.

**Шаг 5 (Деление):** Ошибок нет.

**Вывод:** Единственный дефект — логический: алгоритм реализует поиск максимума вместо минимума. Синтаксис, типы, работа с памятью и отсутствие деления на ноль — в порядке (деления в коде нет вовсе). Границы массива не нарушаются: цикл идёт от `i = 1` до `i < 5`, индексы 1–4 корректны.

**Исправленный код:**

```cpp
#include <iostream>
using namespace std;

int main() {
    int a[5] = {1, 2, 3, 4, 5};
    int min = a[0];
    for (int i = 1; i < 5; ++i) {
        if (a[i] < min)
            min = a[i];
    }
    cout << "min = " << min << endl;
    return 0;
}
```

Вывод программы теперь: `min = 1`.

**Вывод:**

Главный дефект — логическая ошибка: согласно задаче, программа должна находить минимальный элемент массива, но фактически ищет максимальный. В условии `if (a[i] > max)` используется оператор `>`, из-за чего в переменную записывается наибольшее значение. Дополнительно — неудачное имя переменной `max`, которое противоречит смыслу задачи (лучше `min`). В остальном код синтаксически корректен, утечек памяти и выхода за границы массива нет.

**Исправленный код:**

```cpp
#include <iostream>
using namespace std;

int main() {
    int a[5] = {1, 2, 3, 4, 5};
    int min = a[0];
    for (int i = 1; i < 5; ++i) {
        if (a[i] < min)
            min = a[i];
    }
    cout << "min = " << min << endl;
    return 0;
}
```

**Что изменено:**

1. Переменная `max` переименована в `min` — имя теперь соответствует задаче.
2. Оператор сравнения `>` заменён на `<` — теперь ищем минимум, а не максимум.
3. Вывод изменён с `"max = "` на `"min = "` для соответствия результату.

После исправлений программа корректно выведет `min = 1`.
