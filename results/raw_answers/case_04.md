# Кейс №4. Семантическая ошибка (вызов несуществующего метода)

## Ответ модели Yandex GPT

**Шаг 1 (Синтаксис):** Ошибок нет — скобки, точки с запятой и структура программы корректны.

**Шаг 2 (Типы):** Есть ошибки — у `std::vector` не существует метода `push_back_front()`. Это склейка двух разных методов: у `vector` есть только `push_back()` (добавление в конец), а `push_front()` характерен для `std::deque` и `std::list`. Вызов несуществующего метода — ошибка компиляции.

**Шаг 3 (Логика):** Есть ошибки — задача требует добавить элемент в начало вектора, а выбранный (несуществующий) метод по имени намекает на добавление в конец. Даже если автор рассчитывал на `push_back()`, это нарушило бы порядок вывода: получилось бы `1 2 3 0` вместо ожидаемого `0 1 2 3`.

**Шаг 4 (Память):** Ошибок нет — память под вектор управляется автоматически (RAII), утечек, выхода за границы и двойного удаления не обнаружено. `insert` в начале вектора безопасен, хотя и требует сдвига всех элементов (O(n)) — на векторе из трёх элементов это несущественно.

**Шаг 5 (Деление):** Ошибок нет — операций деления в коде нет.

**Вывод:** единственный дефект — вызов несуществующего метода `push_back_front()`, из-за которого программа не скомпилируется. Правильный способ вставить элемент в начало вектора — `insert(v.begin(), 0)` (либо использовать `std::deque`, у которого есть `push_front`).

**Исправленный код:**

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {1, 2, 3};
    v.insert(v.begin(), 0);           // добавляем 0 в начало
    for (int x : v) cout << x << " "; // вывод: 0 1 2 3
    return 0;
}
```

Если вставки в начало будут частыми и порядок элементов важен, стоит рассмотреть `std::deque` — там `push_front` встроен и работает за O(1).

## Ответ модели Qwen

**Шаг 1 (Синтаксис):** Ошибок нет.

Точки с запятой расставлены корректно, скобки парные, структура `main` валидна.

**Шаг 2 (Типы):** Есть ошибки.

Метод `push_back_front` не существует в классе `std::vector`. Компилятор выдаст ошибку: «class std::vector<int> has no member named push_back_front». Для вставки элемента в начало вектора следует использовать `insert(v.begin(), 0)` или `emplace(v.begin(), 0)`.

**Шаг 3 (Логика):** Есть ошибки.

Намерение автора — добавить `0` в начало вектора. Вызов несуществующего метода `push_back_front` не выполняет эту задачу. Даже если бы такой метод существовал, его название противоречит семантике `std::vector` (у вектора есть только `push_back` для конца). Логика не соответствует корректному API контейнера.

**Шаг 4 (Память):** Ошибок нет.

Ручное управление памятью отсутствует, `std::vector` сам освобождает ресурсы. Утечек, выхода за границы и двойного удаления нет.

**Шаг 5 (Деление):** Ошибок нет.

Операции деления в коде отсутствуют.

**Вывод:**

Код не компилируется из-за вызова несуществующего метода `push_back_front`. В `std::vector` нет операции быстрой вставки в начало — для этого используется `insert` с итератором `begin()`, что имеет сложность O(n).

**Исправленный код:**

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {1, 2, 3};
    v.insert(v.begin(), 0);          // вставка 0 в начало вектора
    for (int x : v) cout << x << " ";
    cout << endl;
    return 0;
}
```

Ожидаемый вывод: `0 1 2 3`

**Совет от Senior Developer:** Если в задаче требуются частые вставки в начало — стоит рассмотреть `std::deque` вместо `std::vector`. У `deque` есть метод `push_front()`, который работает за O(1), в отличие от `vector::insert(begin(), ...)`, который сдвигает все элементы за O(n).
