# Датасет тестовых программ на C++ с намеренно внедренными ошибками

Данный файл содержит 10 изолированных программ на C++, использованных для тестирования языковых моделей.

---

## 1. Синтаксическая ошибка — пропущена точка с запятой

**Задача программы:** объявить переменную `x = 5` и вывести её значение на экран.

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 5
    cout << x << endl;
    return 0;
}
```

> **Ошибка:** после `int x = 5` отсутствует `;`.

> **Исправление:** `int x = 5;`

## 2. Синтаксическая ошибка — непарная скобка

**Задача программы:** вывести числа от 0 до 2 через пробел.

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 0; i < 3; ++i) {
        cout << i << " ";
    return 0;
}
```

> **Ошибка:** не закрыта фигурная скобка цикла `for`.

> **Исправление:** добавить `}` перед `return 0;`.

## 3. Семантическая ошибка — несовместимые типы при инициализации

**Задача программы:** создать строковую переменную со значением `"42"` и вывести её.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = 42;
    cout << name << endl;
    return 0;
}
```

> **Ошибка:** число `42` нельзя инициализировать в `string` (нет неявного преобразования).

> **Исправление:** `string name = "42";` (или `to_string(42)`).

## 4. Семантическая ошибка — вызов несуществующего метода

**Задача программы:** добавить число `0` в начало вектора `{1, 2, 3}` и вывести все элементы.

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {1, 2, 3};
    v.push_back_front(0);
    for (int x : v) cout << x << " ";
    return 0;
}
```

> **Ошибка:** у `vector` нет метода `push_back_front` (есть `insert(begin(), ...)` или `push_back`).

> **Исправление:** `v.insert(v.begin(), 0);`

## 5. Логическая ошибка — неверное условие

**Задача программы:** посчитать сумму нечётных чисел от 1 до 10 (ожидается 25).

```cpp
#include <iostream>
using namespace std;

int main() {
    int sum = 0;
    for (int i = 1; i <= 10; ++i) {
        if (i % 2 == 0)
            sum += i;
    }
    cout << sum << endl;
    return 0;
}
```

> **Ошибка:** суммируются чётные числа вместо нечётных.

> **Исправление:** `if (i % 2 != 0)`.


## 6. Логическая ошибка — перепутано сравнение

**Задача программы:** найти минимальный элемент массива `{1, 2, 3, 4, 5}`.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a[5] = {1, 2, 3, 4, 5};
    int max = a[0];
    for (int i = 1; i < 5; ++i) {
        if (a[i] > max)
            max = a[i];
    }
    cout << "max = " << max << endl;
    return 0;
}
```

> **Ошибка:** по смыслу задачи нужно было найти минимум, а ищется максимум.

> **Исправление:** `if (a[i] < max) max = a[i];` (и переименовать `max` в `min`).

## 7. Ошибка времени выполнения — деление на ноль

**Задача программы:** вычислить частное `a / b` для `a = 10`, `b = 0` и вывести результат.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    int b = 0;
    cout << a / b << endl;
    return 0;
}
```

> **Ошибка:** целочисленное деление на ноль — UB, обычно SIGFPE/краш.

> **Исправление:** проверять `b != 0` или использовать ненулевой делитель.

## 8. Ошибка времени выполнения — выход за границы массива

**Задача программы:** вывести все элементы массива `{1, 2, 3}`.

```cpp
#include <iostream>
using namespace std;

int main() {
    int arr[3] = {1, 2, 3};
    for (int i = 0; i <= 3; ++i) {
        cout << arr[i] << " ";
    }
    return 0;
}
```

> **Ошибка:** условие `i <= 3` даёт обращение к `arr[3]` — за границей массива (UB).

> **Исправление:** `i < 3`.

## 9. Ошибка управления ресурсами — утечка памяти

**Задача программы:** заполнить массив из 100 элементов значениями `0..99`; если первый элемент равен 0 — вывести сообщение и завершить функцию; иначе освободить память.

```cpp
#include <iostream>
using namespace std;

void process() {
    int* data = new int[100];
    for (int i = 0; i < 100; ++i) data[i] = i;

    if (data[0] == 0) {
        cout << "empty start\n";
        return;
    }

    delete[] data;
}

int main() {
    process();
    return 0;
}
```

> **Ошибка:** при раннем `return` массив `data` не освобождается — утечка памяти.

> **Исправление:** использовать `vector<int>` или RAII (`unique_ptr<int[]>`), либо освобождать перед `return`.

## 10. Ошибка управления ресурсами — двойное освобождение

**Задача программы:** выделить один `int` со значением `42`, создать второй указатель на тот же блок и освободить память.

```cpp
#include <iostream>
using namespace std;

int main() {
    int* p = new int(42);
    int* q = p;
    delete p;
    delete q;
    return 0;
}
```

> **Ошибка:** `p` и `q` указывают на один блок; второе `delete` — double free (UB/краш).

> **Исправление:** удалять только один раз; лучше `unique_ptr<int>`.
